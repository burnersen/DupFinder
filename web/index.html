Actions

  • Keep: the file stays.
  • Delete: the file goes to the Windows recycle bin (you can restore it from there).
  • Ignore: the file stays where it is and is left out of groups from the next scan on.

Suggested by default: the largest file of each group is marked "Keep", all smaller ones "Delete". You can change that at any time.
