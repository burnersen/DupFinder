Aktionen

  • Behalten: Datei bleibt erhalten.
  • Löschen: Datei wandert in den Windows-Papierkorb (kann von dort wiederhergestellt werden).
  • Ignorieren: Datei wird beim nächsten Scan nicht mehr in Cluster einbezogen, bleibt aber an ihrem Ort.

Standardvorschlag: die größte Datei pro Cluster wird als „Behalten" markiert, alle kleineren als „Löschen". Du kannst das jederzeit ändern.

Lade…

Der Scan läuft im Hintergrund. Sobald Cluster gefunden werden, erscheinen sie hier.

Pfad hinzufügen

Vollständigen Pfad zu einem Verzeichnis eingeben (z.B. D:\Filme).

Nach dem Hinzufügen wird automatisch ein Rescan ausgelöst.
